# breadcrumbs

Custom **breadcrumbs** block. Purpose: hierarchical navigation trail at the top of adventure and magazine detail pages.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one cell containing a list of links (ancestor pages) optionally followed by the current page title as plain text; leave empty to derive the trail from the URL path.

## Supported variations

No variations.
