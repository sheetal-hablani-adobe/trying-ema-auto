# cards

Custom **cards** block. Purpose: default: 4-column grid of image cards with uppercase title and short description; locked: members-only article teasers (faded card, yellow lock badge, title, subtitle, Read more button, image).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: image cell | body cell (heading, text, link).
