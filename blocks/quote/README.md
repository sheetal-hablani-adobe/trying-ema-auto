# quote

Custom **quote** block. Purpose: pull quote with an accompanying large image in magazine articles.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: quotation text; row 2 (optional): attribution, italic text becomes a citation; an image-only cell anywhere becomes the quote image.

## Supported variations

No variations.
