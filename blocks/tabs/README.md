# tabs

Custom **tabs** block. Purpose: default: tabbed content panels (Overview / Itinerary / What to bring) on adventure detail pages; card-grid: category filter tabs over a 4-column grid of adventure cards (Adventures listing).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab: label cell | panel cell(s) (heading, text, images, lists).
